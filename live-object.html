2
State plus event source

The experimental wrapper is deliberately small

class AtmosphereLiveModel extends EventTarget {
  #current;
  #revision = 0;

  get current() { return this.#current; }
  get revision() { return this.#revision; }

  set(axis, value, options) {
    return this.setComposition({ [axis]: value }, options);
  }

  subscribe(listener) {
    const handler = event => listener(event.detail);
    this.addEventListener('atmosphere:change', handler);
    return () => this.removeEventListener('atmosphere:change', handler);
  }
}
No virtual DOM and no style object.

The model records decisions, invokes the current composition controller, observes the compatibility DOM surface, and emits immutable snapshots. CSS continues to resolve the result.

3
Tight relationship

Give a related component the object directly

set model(nextModel) {
  this.#unsubscribe?.();
  this.#model = nextModel;
  this.#unsubscribe = nextModel.subscribe(change => {
    this.#render(change.coordinate, change.changed);
  });
  this.#render(nextModel.current, []);
}
Explicit dependency

The summary clearly declares that it needs the model.

Targeted update

The event says which coordinate fields changed.

Clean lifetime

The setter unsubscribes before binding another instance.

The coordinate summary and token probe on the first view use this pattern.

4
Loose relationship

Bridge global effects without coupling every component

// Adapter: model event → document event
model.subscribe(detail => {
  document.dispatchEvent(new CustomEvent(
    'atmosphere:model-change', { detail }
  ));
});

// Distant subscriber: no model reference
connectedCallback() {
  document.addEventListener(
    'atmosphere:model-change', this.#onChange
  );
}
Use the bridge for global effects, not routine component state.

URL synchronization, analytics, activity feeds, and host-level coordination benefit from decoupling. A closely related view is clearer with a direct dependency.

The activity component in the right rail demonstrates this path. It is never assigned AtmosphereModel.
